# almost-done-studio

> *"почти готово... почти"* 🖋

Инди-студия двух человек — разработчика и 2D-дизайнера.  
Делаем мобильную игру в стиле средневековых рукописей и маргиналии.

## Проект

**[Название игры]** — top-down приключение с персонажами в духе иллюминированных манускриптов.
